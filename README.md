# scientific-ppt-3d-drawing

Codex Skill for high-fidelity reference-image reconstruction and editable 2D, 2.5D, and 3D scientific figures through a structured Microsoft PowerPoint MCP/COM bridge.

Version: 1.1.0

Runtime entry: `SKILL.md`

The Skill includes three video-study batches, source-PPT object catalogues, schemas, deterministic geometry generators, examples, and regression tests. It never uses GUI automation as a fallback.
