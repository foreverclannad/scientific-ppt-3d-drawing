# Periodic structures and membranes

## Purpose

This reference defines deterministic construction for crystals, lattices, layered materials, repeated motifs, polymer-like arrays, planar membranes, curved bilayers, and vesicles. The governing principle is:

> Define one validated motif/template, then generate all placements from a mathematical transform and an explicit boundary rule.

Do not hand-copy large repeated structures.

## 1. Lattice representation

Let lattice vectors be `a`, `b`, and `c`, origin `o`, and basis sites use fractional coordinates `f_m = (u_m, v_m, w_m)`. A generated site is:

```text
p(i,j,k,m) = o + (i + u_m) a + (j + v_m) b + (k + w_m) c
```

for declared repeat ranges in `i`, `j`, and `k`.

A Scene must record:

- lattice vectors and units;
- basis IDs and fractional coordinates;
- repeat counts/ranges;
- boundary convention;
- source file or citation for data-bound structures;
- whether bonds/coordination are supplied, inferred under an explicit rule, or omitted.

Use `scripts/generate_lattice.py` to create stable placements.

## 2. Boundary and duplicate policy

Shared unit-cell boundaries can duplicate sites. Choose one policy:

- **half-open**: include the lower boundary and exclude the upper boundary along each repeated axis;
- **preserve coincident sites (default)**: retain distinct basis/site IDs even when positions coincide, and report the coincidence;
- **explicit deduplicate**: merge positions within a declared tolerance only when the user/source authorizes it, while reporting every dropped site;
- **explicit supercell source**: use exactly the supplied sites and do not add boundaries.

Never silently remove two chemically distinct, disordered, or partially occupied sites merely because their coordinates overlap. `generate_lattice.py` therefore preserves coincident positions by default.

## 3. Bonds and coordination

Default: do not infer bonds.

A bond/edge may be added only when one of these is true:

- explicitly supplied by the source;
- generated by a user-approved distance/radius rule with documented threshold and periodic-image handling;
- used as an illustrative connectivity guide and labeled as such.

Do not infer bond order, oxidation state, coordination number, or periodic connectivity from visual proximity alone.

## 4. Coordination polyhedra and layered materials

For a coordination polyhedron:

1. identify the center and validated neighbor set;
2. generate vertices from supplied coordinates;
3. order faces using a deterministic hull/face definition external to PowerPoint when necessary;
4. create semi-transparent faces with edge outlines;
5. sort faces in camera space;
6. preserve the atoms and polyhedron as separately editable groups.

For layered materials:

- define each layer/motif once;
- derive interlayer offsets and spacing from supplied or illustrative parameters;
- avoid perspective that hides registry/stacking unless an inset provides another view;
- use LOD for distant/repeated atoms rather than exceeding object budgets.

## 5. Level of detail and object budgets

Dense structures can overwhelm PowerPoint. Use staged representations:

- **full editable motif** for a small central region;
- **simplified repeated symbols** for surrounding cells;
- **boundary/outline or external vector/raster asset** for very large domains;
- **inset** for atomistic detail;
- **object budget** declared before expansion.

Generate a low-resolution preview before creating the full structure. Do not increase object count merely to reproduce decorative density.

## 6. Membrane path-frame model

A two-dimensional centerline `r(s) = (x(s), y(s))` defines local frames:

1. tangent:

```text
t = normalize(dr/ds)
```

2. choose an explicit outer-normal convention `n_outer`:

```text
line/wave default: n_outer = (-t_y, t_x)   # left side of path traversal
circle default:    n_outer = normalize(r - center)  # radial outward
```

3. leaflet placements at separation `h`:

```text
r_outer = r + (h/2) n_outer
r_inner = r - (h/2) n_outer
```

For an open line/wave, `outer` and `inner` are relative labels determined by `outer_side`; they are not absolute biological compartments. Each unit is oriented using the local tangent/normal. Use `scripts/generate_membrane.py` for planar, wave, and circular paths.

## 7. Planar bilayer

1. define one lipid template with head, tails, and semantic anchor;
2. generate evenly spaced samples along the centerline;
3. place one leaflet at `+h/2` and the opposite leaflet at `-h/2`;
4. reverse the orientation of the second leaflet so hydrophobic tails face inward;
5. use deterministic IDs such as `membrane.outer.003`;
6. group leaflets separately for later editing.

Counts, molecular identity, and thickness are illustrative unless supplied.

## 8. Curved membrane and vesicle

For a curved membrane:

- orient every unit from its local frame;
- maintain approximately constant leaflet separation;
- avoid bending a pre-flattened bitmap or one monolithic group;
- distribute by arc length when uniform physical spacing matters;
- inspect local crowding on the inner leaflet and gaps on the outer leaflet.

For a circular/vesicle path:

- sample on `[0, 2π)` so the seam does not duplicate the first point;
- ensure the first/last spacing is consistent;
- preserve the intended orientation toward/away from the lumen;
- reduce template size or sample count if the inner leaflet self-overlaps.

## 9. Surface membranes

A true three-dimensional curved membrane requires a surface parameterization and local tangent frame. When that geometry is scientifically material, generate it outside PowerPoint or use a validated external asset. A 2D projected path is suitable for schematic cross-sections, not for claiming a quantitatively accurate 3D membrane surface.

## 10. Shared rules for polymers, helices, and repeated paths

- define a parameterized path;
- sample positions and local orientation deterministically;
- record step size and endpoint policy;
- split paths at crossings when whole-object Z-order cannot express over/under topology;
- preserve semantic IDs and sequence order;
- do not claim a physical conformation without source coordinates.

## 11. QA checklist

Reject or revise when:

- repeated elements were placed manually without a reproducible transform;
- unit-cell boundaries contain unintended duplicates or omissions;
- bonds were inferred without an approved rule;
- generated IDs are unstable or duplicated;
- a membrane leaflet flips orientation unexpectedly;
- circular paths contain a doubled seam object;
- inner/outer leaflet spacing collapses on high curvature;
- object count exceeds the declared budget;
- projection hides the key crystallographic or membrane relation;
- illustrative counts/dimensions are presented as measured values.
