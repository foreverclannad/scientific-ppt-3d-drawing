# Skill assets

The heavy course source-PPT asset library is intentionally stored in the bundled Bridge at:

```text
ppt-codex-bridge/assets/source-pptx
```

This keeps Codex Skill discovery lightweight. Use `ppt_list_assets`, inspect the source slide, then copy only explicit editable objects. Asset metadata and reuse policy are in `references/course-source-ppt-catalog.json` and `references/asset-library-contract.md`.
